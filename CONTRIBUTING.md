# Contributing

This list is a set of starting points, not gospel. If you found numbers that work better, the correction is welcome.

## Proposing a settings correction

Open an issue with these four things:

1. **Style** — the row you're correcting, exactly as it appears in the table.
2. **The numbers you used** — BPM, Weirdness, Style Influence.
3. **What changed** — what the output did differently. "Held the genre through the bridge instead of drifting to pop" is useful; "sounded better" is not.
4. **Model and date** — Suno or Udio, which version, when. These models change, and a setting that was right in March can be wrong in September.

That's it. No template, no CLA, no style guide.

## Adding a style

Same shape, plus the style prompt you used. Styles outside the 59 here are welcome — the catalogue has 564 and this table is a subset.

## What this repo is not

It is not a place to promote a product, mine included. The table links to the catalogue it came from and says so openly in the README; that is the extent of it. Pull requests that add commercial links will be closed.
